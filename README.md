# Gigzen Private Limited — website

Static site. No build step, no dependencies.

**Live:** https://shakhtar-sankur.github.io/gigzen/

| File | Page |
|---|---|
| `index.html` | Company site — products, directors, contact |
| `test-report.html` | Full engineering test report, including what was *not* tested |
| `product-sheet.html` | One-page product sheet |
| `populace.html` | Populace product page |
| `privacy.html` | Buzz privacy policy (used by Google Play) |

Hosted with GitHub Pages from the `main` branch, root folder.
